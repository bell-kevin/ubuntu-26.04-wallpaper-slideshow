Every Ubuntu wallpaper, on rotation.

Ubuntu 26.04 ships with a wallpaper slideshow that Settings can't show you. This small script sets up one that works: all 26 wallpapers, a new one every 5 minutes, with a soft crossfade. Pick a picture whenever you like, or pause on a favorite until you choose to resume.

Why Ubuntu's slideshow is missing

Ubuntu 26.04 includes an “Ubuntu 26.04 Community Slideshow”. It's meant to appear in Settings → Appearance, but the package lists it at the wrong path. Settings skips entries whose file doesn't exist, so it never shows up.

✕ Settings looks for /usr/share/backgrounds/resolute.xml
✓ The file is actually at /usr/share/backgrounds/contest/resolute.xml

This is reported as Launchpad bugs #2152826 and #2155126, confirmed but not yet fixed. Even if you turn Ubuntu's slideshow on by hand, it covers only 21 of the 26 wallpapers and leaves out the default wallpaper itself.

Install

Open Terminal (Ctrl+Alt+T), paste these three lines and press Enter. Your background changes right away.

Terminal
wget https://raw.githubusercontent.com/bell-kevin/ubuntu-26.04-wallpaper-slideshow/main/cycle-desktop-pictures.sh
chmod +x cycle-desktop-pictures.sh
./cycle-desktop-pictures.sh
  • Run it as yourself, not with sudo.
  • Want a different pace? ./cycle-desktop-pictures.sh 20 sets the normal interval to 20 minutes.
  • The script is commented Bash. Read it first if you like.
  • You can delete the script after running it, since its helper keeps a copy. Keep yours if you want to change the interval later.

What you get

Every wallpaper

All 26 pictures that ship with Ubuntu 26.04, in a shuffled order.

Stay as long as you like

Pause on a favorite until you choose to resume. You can also set longer durations for individual pictures; each timed interval includes a 5-second crossfade.

Light and dark style

GNOME keeps a separate background for each style. The script sets both.

Survives every login

Your slideshow or paused picture is remembered after every login and restart.

Pick any picture

Choose one in Settings → Appearance and it shows right away. Rotation continues unless you've paused it.

On the lock screen

GNOME's lock screen shows the current picture, softly blurred.

Everyday use

Jump to a picture
Pick it in Settings → Appearance. Rotation continues unless paused.
Keep this picture
./cycle-desktop-pictures.sh --pause (until you choose to resume)
Resume rotation
./cycle-desktop-pictures.sh --resume (or --unpause)
More time on every rotation
./cycle-desktop-pictures.sh --set-duration 30 (minutes)
Restore its normal duration
./cycle-desktop-pictures.sh --reset-duration
Change the normal interval
./cycle-desktop-pictures.sh 20 (minutes per picture; keeps custom durations)
Reshuffle the order
Run the script again while rotating.
Stop and uninstall
./cycle-desktop-pictures.sh --stop (the current picture stays)
Start after uninstalling
Run the script again.
Other accounts
The setting is per account. Each person runs the script once while logged in as themselves.

To keep one of Ubuntu's pictures on screen, pick it in Settings → Appearance, then run ./cycle-desktop-pictures.sh --pause. It stays until you run ./cycle-desktop-pictures.sh --resume, even after logging out or restarting. Picking another picture while paused changes the picture and keeps rotation paused. Resuming starts a fresh interval from the currently selected picture.

Pause keeps your interval, custom durations, and helper installed. Rerunning the script or changing the interval or custom durations won't unpause it; duration changes are saved for when you resume. You can also pause on a picture by its local file path:

Terminal
./cycle-desktop-pictures.sh --pause /usr/share/backgrounds/warty-final-ubuntu.png

For a longer timed stay on every rotation, pick a picture and run ./cycle-desktop-pictures.sh --set-duration 30. While rotating, this starts a fresh 30 minutes for that picture right away; other pictures keep their usual interval. While paused, it saves the duration for later. Its custom duration applies each time it appears, including after picking it again, logging in, or rerunning the script.

Both --set-duration MINUTES [PICTURE] and --reset-duration [PICTURE] use the currently visible picture if you leave out PICTURE. To choose a picture by its local file path instead:

Terminal
./cycle-desktop-pictures.sh --set-duration 30 /usr/share/backgrounds/warty-final-ubuntu.png

Quote paths that contain spaces. Durations must be positive whole minutes and include the 5-second crossfade. --reset-duration restores the normal interval for just that picture; you can pass the same file path to reset it while another picture is showing.

--stop also uninstalls: it removes the helper and every file the script created, including the pause state and saved custom durations. If you've deleted the script, run the copy the helper uses:

Terminal
~/.local/share/wallpaper-slideshow/cycle-desktop-pictures.sh --stop

Only want Ubuntu's own slideshow?

Ubuntu's built-in slideshow has 21 pictures at 30 minutes each. To switch to it for your account, first run ./cycle-desktop-pictures.sh --stop if you've been using this script, or it takes over again the next time you pick a picture. Then:

Terminal
gsettings set org.gnome.desktop.background picture-uri file:///usr/share/backgrounds/contest/resolute.xml
gsettings set org.gnome.desktop.background picture-uri-dark file:///usr/share/backgrounds/contest/resolute.xml

Or fix the broken entry for everyone on this computer, so the slideshow shows up in Settings. This edits a file that belongs to the ubuntu-wallpapers-resolute package, so a future update to that package will replace it.

Terminal
sudo sed -i 's:backgrounds/resolute.xml:backgrounds/contest/resolute.xml:' /usr/share/gnome-background-properties/resolute-wallpapers.xml

If gsettings says No such key "picture-uri-dark", you're in the terminal of a snap app such as VS Code. Use the regular Terminal app instead.

How it works

GNOME Shell can play a slideshow described by an XML file: a list of pictures with how long to show each one and how long to fade between them. The script builds one and hands it to GNOME.

  1. Finds the pictures. Every image in /usr/share/backgrounds, with symlinks resolved so a picture with two names appears once.
  2. Writes a slideshow file. A shuffled list in ~/.local/share/wallpaper-slideshow/, using each picture's custom duration or the normal interval. At the default 5 minutes, that's 4 minutes 55 seconds followed by a 5-second fade.
  3. Sets your background. Points picture-uri and picture-uri-dark at the slideshow. GNOME Shell does the rest.
  4. Starts a helper. A systemd user service, wallpaper-slideshow.service, waits for your background setting to change. Unless paused, picking a picture makes it write a new slideshow that starts with it and switches over about a second later.

Each new slideshow gets a new file name, because GNOME Shell caches slideshows by name and would otherwise keep the old order until you log out. A picture of your own works too: it's shown first and stays in the rotation until you pick another. Tested on Ubuntu 26.04.1 LTS with GNOME Shell 50.1.
